# houseplan-card #1603 — HA E2E: не надо

Источник: https://github.com/Matysh/houseplan-card/issues/1603.

Изменение запрещает неявные типы any в TypeScript и добавляет адресный Ruff+mypy только для существующих изменённых исходников custom_components/houseplan/**/*.py. Обновлены предметные типы/вывод типов; модель, сохранение, действия пользователя, доступы и HA API не меняются. Это не новое пользовательское поведение и не новый маршрут импорта/обновления.

Проверки самой задачи: обычный npm run typecheck с noImplicitAny:true; реальные положительный и отрицательные CLI witnesses Ruff/mypy (неизвестное имя, неверный return type, неизменённый ошибочный сосед не проверяется); planner cases точного списка, дублей/удалений, Python-подготовки CI, отсутствия шага без бэкенда и нулевого docs-плана. Существующие backend contracts кодов ошибок, локализации, модульной идентичности и noexcept/noqa сохранены. Прежний рейтчет роста strict-allowlist удалён.

Финальный S6 и независимое код-ревью выполняются через native queue; фактические результаты принадлежат исходной issue, документ не объявляет их выполненными заранее. Новые HA journeys/визуальные эталоны не требуются; общий release-набор остаётся прежним.
