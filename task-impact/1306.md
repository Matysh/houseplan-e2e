# #1306 — node-save validation work

Source: https://github.com/Matysh/houseplan-card/issues/1306

Перед beta.7 реализованы три настоящих HA pointer journeys в `tests/node-save.admin.spec.mjs`: Move/independent Merge с двумя пространствами, adjacent Merge с удалением ребра и stale CAS, unsafe foreign refusal. Сохранены ACK boundary, exact Undo/Redo, reload и нетронутое скрытое пространство. Фикстуры исправлены в companion #29, viewport готовится публичными zoom controls. На продуктовом исправлении #1320 (`3e940259`) — 3/3 business + 3/3 setup PASS без skip/retry/unexecuted, HA 2026.10.4. Полный release-набор отдельно должен зачесть итоговый E2E commit; адресный прогон не называется полным stable.

Вердикт: **надо**, до беты. В geometry journey проверить обычный Move и Merge с двумя пространствами: одинаковый финальный candidate, pending до ACK, ровно один accepted Store/revision/history шаг; reload и exact Undo/Redo. Отказы: foreign geometry вне viewport, stale CAS, revoked permission, ошибочный host/before_space и storage failure. Повторить после cold start и серии последовательных сохранений, чтобы schema stamp не пропускал новую ошибку и не сбрасывался после каждого успешного node write. Timing и число реальных expensive passes записывать отдельно, не считать fake ACK доказательством HA Store.

Внутри задачи: адресные cache mutation/context/ownership negative controls, проверка отсутствия model11 all-pairs, настоящий authenticated HA WS/Store/stamp/ACL/CAS/reload/Undo, native pointer observer реального junction guard и CPU before/after на 100/1000/5000 рёбер. Изменения реальных HA journeys — перед бетой.
