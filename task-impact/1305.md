# #1305 — объединение узлов перетаскиванием

Источник: https://github.com/Matysh/houseplan-card/issues/1305

Перед beta.7 реализованы три настоящих HA pointer journeys в `tests/node-save.admin.spec.mjs`: Move/independent Merge с двумя пространствами, adjacent Merge с удалением ребра и stale CAS, unsafe foreign refusal. Сохранены ACK boundary, exact Undo/Redo, reload и нетронутое скрытое пространство. Фикстуры исправлены в companion #29, viewport готовится публичными zoom controls. На продуктовом исправлении #1320 (`3e940259`) — 3/3 business + 3/3 setup PASS без skip/retry/unexecuted, HA 2026.10.4. Полный release-набор отдельно должен зачесть итоговый E2E commit; адресный прогон не называется полным stable.

Вердикт: **надо**. До следующей беты расширить geometry/node journey реального HA: магнит и подсветка неподвижного узла в Select; независимые узлы и соседние узлы с атомарным удалением соединяющего ребра; потеря комнаты/проём на удаляемом ребре/опасные углы и valence — полный отказ без обычного Move. Проверить один ACK, exact store/reload, Undo/Redo, устаревший expected_rev, потерю права, старый backend без capability. Простой клик с соседним узлом в 10 CSS px не должен объединять или сохранять.

В самой задаче: синтетические TS/Python общие fixtures и полное сравнение конфигураций, аутентифицированные HA WS/store/CAS/reload/Undo/Redo проверки, native pointer smoke с production Python proof, отложенным ACK, отказами и 5000-рёберным held drag. Этот wire smoke дополняет HA backend tests, но не подменяет полный браузерный HA E2E. Изменения самих HA journeys выполняются перед бетой.
