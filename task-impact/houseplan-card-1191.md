# houseplan-card#1191 — влияние на HA E2E

Вердикт: **не надо**.

Исходная задача: https://github.com/Matysh/houseplan-card/issues/1191.

Отчёт Golden теперь отдельно фиксирует SHA фактического checkout и исходный SHA события workflow_dispatch. Это исправляет определение снятого материала при резервном запуске; правила принятия кадров и сверка HEAD сохраняются. Продуктовые UI/API/права/хранение и HA E2E сценарии не меняются. Адресная регрессия использует собственный временный Git репозиторий и dry-run приёмщика, без автоматического принятия кадров. Синтаксис и13проверок механизма прошли в исходной задаче.
