# houseplan-card #1346

Вердикт: **надо**, дополнение существующего geometry / Plan-editor journey перед следующей бетой.

Сценарий: текущий model11, замкнутый периметр с внутренней тупиковой перегородкой (с проёмом вне стыка). План → Выбрать: наведение подсвечивает свободную замкнутую область; клик открывает штатный диалог. Cancel не пишет геометрию. Confirm создаёт одну комнату после ACK, сохраняет тупиковую перегородку и её проём без автоматического соединения конца. Проверить точные Undo/Redo и reload. Отрицательный вариант с настоящим разрывом периметра не подсвечивается и не создаёт комнату.

Имеющийся native smoke покрывает UI через синтетический transport; это не доказательство реального HA ACK/Store. Обычные ACL/CAS/сохранение/безопасность не меняются, ослаблять их не требуется.

Репорт hpr-c07b164fc6 остаётся приватным. Для регрессии использовать синтетический эквивалент test/fixtures/1346-room-face-spurs.json из card repo, без данных и контактов пользователя.
