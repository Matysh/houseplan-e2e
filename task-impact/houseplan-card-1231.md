# #1231 — HA E2E: не надо

Источник: https://github.com/Matysh/houseplan-card/issues/1231.
Принятый test SHA: f4b8e2b38eafcfb3a1aa232f8d9d34c34eb6abe8.

Продукт не менялся. Ошибочный регрессионный сценарий выбирал rooms[0] после
канонической сортировки model11 и переносил другую комнату поверх существующей.
Родитель Split теперь определяется по стабильному ID left-r. На неизменном
продукте минимальные две комнаты и исходные146 комнат дают корректный Split;
общая стена/соседи/точная история сохраняются. Настоящий третий владелец и
исходное ошибочное наложение продолжают отклоняться.

Обновлять ожидание продукта или ослаблять HA exact/ownership oracle не нужно.
Остальная подготовка существующих Split journeys остаётся в #1225/#1226.
