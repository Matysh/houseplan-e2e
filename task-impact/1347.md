# houseplan-card #1347

Вердикт: **надо**, выполнено при подготовке 1.85.1-beta.1.

Нативная команда HA drawer и переходы редакторов проходят через реально видимый общий menu, когда исходные header controls скрыты. В helpers/header-actions используются объявленные hooks и исходные accessible names, без force/private product writes. panel.mobile (в fixed beta13) проверяет touch-trigger -> menu item -> настоящий HA drawer; panel-header admin сохраняет native sidebar preference, source ownership и 44px, проверяя доступные команды через общий menu. Исторические версии без нового declared hook сохраняют прямой путь.
