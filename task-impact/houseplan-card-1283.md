# #1283 — HA E2E: надо

Источник: https://github.com/Matysh/houseplan-card/issues/1283.
Принятый product SHA: 7acb943e7ddfbf339c5181307f495d81ef6d3712.

В существующем путешествии редактора нарисовать комнату с дополнительным
коллинеарным кликом; на её стене создать T-перегородку и увести её либо удалить.
По настоящему server config/get проверить отсутствие лишнего безопасно
схлопываемого шва, положения и exact host существующего проёма, затем Undo/Redo,
reload и Optimize без изменений. Отдельный незавершённый Draw должен принимать
следующий клик: промежуточные ID цепочки не теряются до её завершения.

Разная толщина/props, зависимость-опора и проём через шов должны сохранять
соответствующий узел; полный набор отрицательных геометрических условий остаётся
в адресных тестах механизма. Совместить с #1282, не дублировать весь генератор
последовательностей в HA. Этот real HA сценарий ещё не выполнялся; учесть перед бетой.
